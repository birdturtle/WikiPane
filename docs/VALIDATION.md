# Validation guide

This file indexes current verification rather than duplicating the integration roadmap.

- [Testing and manual acceptance](TESTING.md): build commands and gameplay gates.
- [Presentation validation](PRESENTATION_VALIDATION.md): composition contracts, provenance coverage and safe fallback.
- [Map coverage audit](MAP_COVERAGE_AUDIT.md): actual Wiki geometries, pixel checks and native-map limits.
- [Plugin Hub readiness](PLUGIN_HUB.md): packaging/dependency review and submission steps.

Semantic coverage means source units have destinations in the complete reader. It does not mean every specialized interpretation or every article on the Wiki is verified. Compact inspections intentionally select a subset while preserving access to the original article.
